### Create tree.py

Added Binary Search Tree (BST) implementation with support for inserting values and searching within the tree. The implementation includes a Node class to represent individual tree nodes and a BinarySearchTree class that manages the tree structure. Both insert and search operations leverage the BST property where values smaller than a node are placed in the left subtree and larger values in the right subtree, enabling efficient O(log n) average-case operations.
